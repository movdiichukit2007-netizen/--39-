# PostalApi

Практична робота: "Виокремлення бізнес-логіки в сервісний рівень".

Проєкт створено на базі ASP.NET Core Minimal API (.NET 8). Він демонструє простий сервіс поштових відправлень з окремими моделями, DTO, mapper-класом та сервісним рівнем.

## Структура проєкту

- `Models` - моделі даних.
- `Dtos` - об'єкти для передачі даних.
- `Mappings` - перетворення між DTO та моделями.
- `Services` - бізнес-логіка.
- `Program.cs` - налаштування API-маршрутів.

## Запуск

```bash
dotnet run
```

## Основні маршрути

- `GET /postings` - отримати всі відправлення.
- `GET /postings/{id}` - отримати відправлення за id.
- `POST /postings` - створити нове відправлення.
- `PUT /postings/{id}` - оновити відправлення.
- `DELETE /postings/{id}` - видалити відправлення.

## Висновок

У цій практичній роботі було створено простий вебсервіс для роботи з поштовими відправленнями. Бізнес-логіку винесено в окремий сервісний рівень, що робить код зрозумілішим і зручнішим для підтримки. Для передачі даних використано DTO, а для перетворення об'єктів створено окремий mapper. Minimal API дозволив швидко описати потрібні HTTP-маршрути без зайвого коду.
